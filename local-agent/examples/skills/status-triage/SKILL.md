---
name: status-triage
description: 根据最新状态记录列出异常、影响与最小下一步，适用于服务状态或项目健康检查。
metadata:
  version: "1.0"
  author: Local Agent Runtime example
compatibility: 需要本轮可用的状态读取工具；没有工具时只能说明缺少当前数据。
---

1. 先明确本次要检查的对象，用当前获准工具获取最新状态。
2. 只把结果中实际出现的异常写入清单；区分明确失败、信息缺失和正常项。
3. 每项说明观察到什么、直接影响什么、下一步最小验证是什么。没有证据时不猜测根因。
4. 为状态值保留 Runtime 的来源引用和记录时间。若用户在问变化，先取得可比的历史值；不能把旧值当成最新值。
5. 已有证据足够回答时结束；遇到读取失败说明失败及未验证部分。遵守工具预算、取消和权限边界。

本 Skill 只提供检查方法，不授权修复、重启服务、运行脚本或对外发送消息。
