先用 read_skill 读取本包 references/source-checklist.md，再整理事实。

1. 从用户问题确认项目、时间范围和是否需要保存报告。
2. 使用当前获准的文件或 MCP 工具取得数据。当前状态需要本轮重新读取，历史值须标出当时的时间。
3. 按“当前进展、主要风险、下一步”组织简报，区分原文事实、推断和未知项。矛盾信息并列说明。
4. 为事实使用 Runtime 支持的来源引用。只有方法来自本 Skill，项目事实必须来自实际项目数据。
5. 用户要求保存时，按给定输出路径调用现有写入工具，遵守预览与审批流程；收到写入回执后再声称文件已创建。

工具或材料缺失时说明缺项，保持已有权限，不执行随包脚本。
